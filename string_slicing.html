Cut any string exactly where you want.

String slicing lets you pull out any part of a string using three numbers — start, stop and step — without writing a single loop.

# s = "PYTHON"
s[1:4]  -> "YTH"
s[::-1]  -> "NOHTYP"
s[-3:]   -> "HON"
introduction

What is string slicing?

A string in Python is a sequence of characters, and every character has a position (index). Slicing means asking Python for a *range* of positions at once — s[start:stop:step] — instead of one character with s[i]. It is used everywhere: cleaning text, reversing words, extracting file extensions, parsing dates, and processing data.
